# Atlas konspiraci: redakcni korpus

Tento repozitar slouzi pouze pro rucni redakcni kontrolu publikovanych hesel.

Obsah:
- `published/` obsahuje hotove markdowny urcene k redakci
- `STYLEGUIDE.md` obsahuje pravidla editace
- `ASSIGNMENTS.md` slouzi pro rozdeleni prace mezi editory

Zakladni pravidla:
- Upravujte pouze soubory v `published/`
- Nemente `slug`
- Nemazte sekce `Shrnuti`, `Overeni`, `Sireni v CR/SR`, `Zdroje`
- Nepridavejte nove sekce bez domluvy
- Jeden pull request ma resit maly a souvisly balik souboru

Doporuceny workflow:
1. Otevrit konkretni soubor v GitHubu
2. Kliknout na editaci
3. Commitnout do vlastni branche
4. Otevrit pull request
